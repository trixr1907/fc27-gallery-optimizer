Settings

Plan method: the first calculation is one global portfolio search with a shared time budget — branch & bound over the shared card set with a memoized set evaluation and an admissible monotone bound, then a 2-opt refinement, under the coin budget. It returns the best plan found inside its budget and labels it proven optimal (the search completed under the bound) or best found (the budget was spent) — never a truncated search presented as optimal. Each shared card is bought once and its cost charged once against coins − reserve. Per-set plans are computed on demand, in background batches, so the page stays responsive.

Import / export state

Import a JSON snapshot containing players, galleries, and optional settings. Older saves are migrated forward automatically (schema v2).

Prices are dated snapshots. Every buy/resale price is stored with the moment it was read, so a stale price is never mistaken for a current one. Re-enter a price to refresh its snapshot date.

FUT.GG set importer

Paste a FUT.GG Gallery-set URL. The server imports set metadata (slots, thresholds, rewards) as a dated snapshot; repeated imports of the same URL are served from a short-lived cache.
