Settings

Plan method: branch & bound over candidate card sets (memoized set evaluation, admissible monotone bound), then a 2-opt refinement, with a coin-budget cap. The plan reports whether it is proven optimal (search exhausted under the bound) or only the best found because the node cap was hit. The global portfolio plan buys each shared card once, charges its cost once, and spends the shared budget coins − reserve; beyond a small universe it runs the same branch & bound over the shared card set, and again reports proven optimal vs best found (node limit).

Import a JSON snapshot containing players, galleries, and optional settings. Older saves are migrated forward automatically (schema v2).

Prices are dated snapshots. Every buy/resale price is stored with the moment it was read, so a stale price is never mistaken for a current one. Re-enter a price to refresh its snapshot date.

FUT.GG set importer

Paste a FUT.GG Gallery-set URL. The server imports set metadata (slots, thresholds, rewards) as a dated snapshot; repeated imports of the same URL are served from a short-lived cache.
